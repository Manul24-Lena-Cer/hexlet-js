## Development

### Code Linting

We use ESLint to maintain code style consistency. Use the following commands:

* `make lint` — check code for style issues and potential problems.
* `make lint-fix` — automatically fix most style issues in your code.

**Examples:**

```bash
# Check code for linting issues
make lint

# Automatically fix linting issues
make lint-fix
Recommendations:

Run make lint before committing your code.

Use make lint-fix to quickly fix style issues.
